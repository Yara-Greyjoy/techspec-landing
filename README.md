# Лендинг технического специалиста

Личный сайт-портфолио Анастасии: услуги по GetCourse, чат-ботам Salebot, автоматизации и сопровождению запусков. Разработан с помощью ИИ.

## Как посмотреть

Скачайте репозиторий и откройте `index.html` в браузере. Установка зависимостей и сборка не нужны. Для шрифта Inter используется Google Fonts; без подключения к нему применяется системный шрифт.

## Возможности

- Адаптивная вёрстка для компьютеров и телефонов.
- Блоки опыта, услуг, этапов работы и контактов.
- Карусель кейсов, подробные описания и галереи изображений.
- Полноразмерный просмотр с масштабированием и навигацией внутри кейса.
- Декоративные анимации с учётом настройки уменьшения движения.

## Устройство

- `index.html`: HTML, CSS и JavaScript страницы.
- `case-content.json`: данные кейсов; их копия встроена в HTML для работы без сервера.
- `assets/cases/`: изображения кейсов.
- `Gemini_Generated_Image_wyrh12wyrh12wyrh.png`: изображение первого экрана.
- `.gitignore`: исключения для локальных файлов, секретов и временных артефактов.
- `.env.example`: пустой учебный пример переменной; лендинг не использует секреты или серверную часть.

При редактировании кейсов синхронизируйте JSON и встроенные данные `case-data` в HTML. Учебные и демонстрационные проекты обозначены в описаниях. Публикация репозитория сама по себе не размещает сайт в интернете.

В этом репозитории находится публичная копия проекта. Внутренние рабочие инструкции, заметки и локальная история разработки в неё не включены.
